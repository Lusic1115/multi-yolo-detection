# 多场景 YOLO 智能视觉检测平台

本项目是一个基于 YOLO 的多用途目标检测系统，面向不同场景提供图片检测、视频检测、摄像头实时检测、模型管理、检测历史管理和 AI 智能分析能力。系统支持通用目标检测、无人机检测、火灾检测、花卉检测、病虫害检测等场景，用户可以根据检测任务选择对应场景和模型，系统会完成目标识别、结果可视化、置信度统计、历史保存和自然语言分析。

## 项目定位

### 工作台界面更新（2026-10）

本次更新保留原项目基础，在此之上重新设计前端与检测交互：

- 工作概览：真实账号统计、场景入口、目标分布和历史结果快照。
- 检测工作台：先选模型与文件，再点击开始检测；支持原图/结果切换、JSON 导出和结果文件下载。
- 检测参数：可按次调整置信度阈值（0.01–0.95），后端实际用于图片、视频与摄像头推理。病虫害默认 0.05，其他场景默认 0.25；低阈值可能增加误检，不代表精度提升。
- 模型状态：模型未加载成功时不能开始检测；若另一页面更换了模型，服务端会拒绝模型不一致的检测请求。
- 检测记录：文件名/类别/ID 搜索、类型与日期筛选、待复核筛选、筛选结果 CSV 导出及单条 JSON 导出。
- 模型资源：名称搜索、场景筛选、大小/时间排序、上传前重命名与场景关键词匹配预览。
- 小 Y 助手：侧栏打开的问答抽屉；标明 DeepSeek 回答或本地回答，显示等待状态。

摄像头采用逐帧串行请求，不自动录制或保存历史。视频统计为采样帧中的目标次数，不是去重后的目标个数。网页版模型上传限制为 100 MB，较大模型可直接放入 `models/` 后刷新。

后端新增参数回归检查：在已安装后端依赖的环境运行 `python -m unittest discover -s tests -v`。
前端导出与场景规则检查：安装前端依赖后，用 Node.js 22.7+ 运行 `node --test tests/test_workspace.mjs`。

传统目标检测系统通常只面向单一场景，模型切换和结果分析依赖人工操作。本项目将 YOLO 检测能力扩展为多场景检测平台，通过前端场景选择、后端模型加载、MySQL 数据存储和 DeepSeek 智能问答，实现从“上传数据”到“检测分析”再到“结果复查”的完整流程。

系统主要适用于以下场景：

- 通用检测：识别日常图片或视频中的常见目标。
- 无人机检测：用于低空飞行目标识别和安全监测。
- 火灾检测：识别火焰、烟雾等风险目标，辅助安全预警。
- 花卉检测：识别花卉类别或花朵目标，适合花卉识别展示。
- 病虫害检测：识别植物病害、虫害或叶片异常，辅助农业植保判断。

## 技术栈

后端技术：

- Flask：提供 Web API 服务。
- YOLOv8 / Ultralytics：完成目标检测推理。
- OpenCV：处理图片、视频和摄像头帧。
- Flask-SQLAlchemy：管理数据模型和数据库操作。
- PyMySQL：连接 MySQL 数据库。
- DeepSeek API：生成检测报告和智能问答内容。

前端技术：

- Vue 3：构建前端单页应用。
- Vue Router：管理页面路由。
- Vuex：管理用户登录状态和全局请求状态。
- Element Plus：提供按钮、表格、弹窗、上传等 UI 组件。
- Axios：向后端发送接口请求。

数据库：

- MySQL：保存用户信息和检测历史记录。

## 核心功能

### 1. 用户登录与注册

系统提供登录、注册和找回密码页面。用户登录后进入主界面，系统会保存当前用户状态，并根据登录状态控制页面访问。

主要功能包括：

- 用户登录
- 新用户注册
- 密码找回与重置
- 登录状态校验
- 退出登录

默认测试账号：

```text
用户名：admin
密码：admin123
```

### 2. 工作概览

工作概览展示当前账号的检测统计、待复核任务、模型覆盖场景、目标分布及最近结果快照，可直接进入检测或查看历史详情。

首页主要说明：

- 系统支持图片、视频、摄像头三类输入。
- 系统支持多场景模型切换。
- 检测结果可保存到历史记录。
- AI 分析可以增强检测结果解释能力。

### 3. 目标检测

目标检测页面是系统的核心页面，用户可以选择检测方式、检测场景和场景模型。

检测方式包括：

- 图片检测：上传 JPG、PNG、GIF 等图片文件，系统返回带检测框的结果图片。
- 视频检测：上传 MP4、AVI、MOV 等视频文件，系统生成带检测框的结果视频。
- 摄像头检测：调用本机摄像头，对实时画面进行目标检测。

检测结果包括：

- 目标类别
- 检测置信度
- 目标框坐标
- 目标总数
- 平均置信度
- 最高置信度
- 低置信度目标数量
- 类别分布
- 结果图片或结果视频

### 4. 场景选择与自动模型切换

检测页面提供场景按钮，用户检测什么场景就点击什么场景。系统会根据场景自动匹配对应模型，避免使用错误模型导致 AI 分析角色不匹配。

当前支持场景：

| 场景 | 用途 | 默认逻辑 |
|---|---|---|
| 通用检测 | 识别日常常见目标 | 使用通用 YOLO 模型 |
| 无人机检测 | 识别无人机、飞行器等低空目标 | 自动匹配无人机模型 |
| 火灾检测 | 识别火焰、烟雾等风险目标 | 自动匹配火灾模型 |
| 花卉检测 | 识别花卉和花朵目标 | 自动匹配花卉模型 |
| 病虫害检测 | 识别植物病害、虫害或叶片异常 | 自动匹配病虫害模型 |

如果某个场景下有多个模型，页面会显示模型选择框，用户可以手动选择具体使用哪个 `.pt` 模型。例如同一场景可以同时上传不同大小或不同版本的模型。

### 5. 模型管理

模型管理页面用于维护系统中的 YOLO 模型文件。

主要功能包括：

- 查看当前正在使用的模型。
- 查看项目中可用的模型列表。
- 上传新的 `.pt`、`.onnx` 或 `.torchscript` 模型。
- 加载指定模型。
- 删除不需要的模型。
- 查看模型类别数量和类别名称。
- 查看场景模型命名规则。

### 6. 检测历史

检测记录页面用于保存和复查图片、视频检测任务，结果写入 MySQL。摄像头逐帧检测不自动保存历史记录。

历史记录支持：

- 查看检测时间
- 查看检测类型
- 查看原始文件名
- 查看最高置信度
- 查看检测详情
- 预览结果图片或结果视频
- 下载结果文件
- 删除单条记录
- 批量删除记录
- 清空当前用户历史记录
- 查看历史统计分析

历史分析内容包括：

- 历史检测次数
- 图片、视频、摄像头检测数量
- 历史平均置信度
- 低置信度记录数量
- 累计目标数量
- 常见类别统计

### 7. AI 自然语言分析

系统接入 DeepSeek，用于对检测结果生成自然语言解释。AI 分析会结合当前选择的检测场景，切换不同回答角色。

不同场景对应的 AI 角色：

| 场景 | AI 角色 | 回答重点 |
|---|---|---|
| 通用检测 | 通用目标检测助手 | 解释主要目标、置信度、类别分布和检测可靠性 |
| 无人机检测 | 低空安全监测助手 | 关注无人机目标、低空安全、复核建议 |
| 火灾检测 | 安全预警助手 | 关注火焰、烟雾、风险等级和处置建议 |
| 花卉检测 | 花卉识别助手 | 关注花卉目标、类别识别和结果说明 |
| 病虫害检测 | 农业植保助手 | 关注病虫害表现、叶片异常和农业处理建议 |

AI 分析能力包括：

- 生成检测结果报告。
- 解释检测结果是否可靠。
- 分析低置信度目标。
- 给出人工复核建议。
- 围绕当前检测结果继续问答。

如果没有配置 DeepSeek API Key，系统会返回本地兜底说明，保证功能不会完全中断。

### 8. 小 Y 检测助手

小 Y 检测助手是页面右下角的项目说明助手，主要用于解释系统功能和页面分布。它和“检测结果智能问答”不同：

- 小 Y 检测助手：回答项目本身怎么用、功能在哪里、模型怎么命名、AI 角色如何切换。
- 检测结果智能问答：基于当前一次检测结果，回答目标、置信度、风险、复核建议等问题。

小 Y 支持的问题示例：

- 这个系统有哪些页面？
- 怎么进行检测？
- 模型应该怎么命名？
- AI 角色怎么切换？
- 历史记录在哪里看？

## 场景模型命名规则

为了让系统能够按场景自动匹配模型，上传模型时建议按照以下规则命名。文件名可以包含版本号和模型大小，但必须包含对应场景关键词。

| 场景 | 推荐命名 | 可识别关键词 |
|---|---|---|
| 通用检测 | `models/yolov8n.pt`、`general_yolov8n.pt`、`common_yolov8s.pt` | `general`、`common`、`通用`、默认模型 |
| 无人机检测 | `drone_yolov8n.pt`、`uav_yolov8s.pt`、`drone_v2_best.pt` | `drone`、`uav`、`无人机`、`飞行器` |
| 火灾检测 | `fire_yolov8n.pt`、`smoke_yolov8s.pt`、`fire_v2_best.pt` | `fire`、`flame`、`smoke`、`火灾`、`火焰`、`烟雾` |
| 花卉检测 | `flower_yolov8n.pt`、`rose_yolov8s.pt`、`flower_v2_best.pt` | `flower`、`rose`、`sunflower`、`tulip`、`daisy`、`花卉`、`花朵` |
| 病虫害检测 | `pest_yolov8n.pt`、`disease_yolov8s.pt`、`leaf_pest_best.pt` | `pest`、`disease`、`leaf`、`plant`、`病虫害`、`病害`、`虫害`、`叶片` |

推荐命名格式：

```text
场景关键词_yolo版本_模型大小_版本号.pt
```

示例：

```text
drone_yolov8n_v1.pt
fire_yolov8s_v2.pt
flower_yolov8m_best.pt
pest_yolov8n_202606.pt
general_yolov8n.pt
```

## 系统运行流程

整体使用流程如下：

1. 用户登录系统。
2. 进入模型管理页面，上传或确认需要使用的 YOLO 模型。
3. 进入目标检测页面。
4. 选择检测方式：图片、视频或摄像头。
5. 选择检测场景：通用、无人机、火灾、花卉或病虫害。
6. 系统根据场景自动匹配模型，也可以手动选择同场景下的其他模型。
7. 选择文件、调整阈值并点击开始检测，或在实时模式启动摄像头。
8. 查看检测框、类别、置信度、统计结果和结果文件。
9. 使用 AI 生成自然语言报告或继续追问检测结果。
10. 在历史记录页面复查、下载或删除检测记录。

## 后端接口概览

用户相关：

- `POST /api/login`：用户登录。
- `POST /api/register`：用户注册。
- `POST /api/reset_password`：重置密码。

检测相关：

- `POST /api/detect_image`：图片检测。
- `POST /api/detect_video`：视频检测。
- `POST /api/detect_camera`：获取摄像头模式配置，不保存检测记录。
- `POST /api/process_frame`：实时摄像头帧检测。

AI 分析相关：

- `POST /api/analysis/report`：生成检测结果 AI 报告。
- `POST /api/analysis/chat`：围绕检测结果继续问答。
- `POST /api/project_assistant/chat`：小 Y 项目助手问答。

历史记录相关：

- `GET /api/history/<user_id>`：获取用户检测历史。
- `DELETE /api/history/delete/<record_id>`：删除单条历史。
- `DELETE /api/history/batch-delete`：批量删除历史。
- `DELETE /api/history/clear/<user_id>`：清空用户历史。
- `GET /api/analysis/history/<user_id>`：获取历史统计分析。

模型管理相关：

- `GET /api/models`：获取模型列表。
- `GET /api/models/current`：获取当前模型。
- `POST /api/models/load`：加载指定模型。
- `POST /api/models/upload`：上传模型。
- `DELETE /api/models/delete`：删除模型。
- `GET /api/models/scenario/<scenario>`：获取指定场景可用模型。
- `POST /api/models/load_by_scenario`：按场景加载模型。

## 数据库说明

系统使用 MySQL 保存用户和检测记录。默认数据库名为：

```text
yolo_detection
```

可以通过环境变量配置数据库连接：

```bash
export MYSQL_USER="root"
export MYSQL_PASSWORD="你的MySQL密码"
export MYSQL_HOST="localhost"
export MYSQL_PORT="3306"
export MYSQL_DB="yolo_detection"
```

如果本机 MySQL 没有密码，可以将 `MYSQL_PASSWORD` 设置为空：

```bash
export MYSQL_PASSWORD=""
```

主要数据表：

### user 表

| 字段 | 说明 |
|---|---|
| id | 用户 ID |
| username | 用户名 |
| password | 密码 |
| created_at | 创建时间 |

### detection_result 表

| 字段 | 说明 |
|---|---|
| id | 检测记录 ID |
| user_id | 用户 ID |
| detection_type | 检测类型，包含 image、video、camera |
| original_file | 原始文件名 |
| result_file | 结果文件名 |
| detections | 检测结果 JSON |
| confidence | 最高置信度 |
| created_at | 检测时间 |

## DeepSeek API Key 配置

检测结果 AI 报告和智能问答需要 DeepSeek API Key。系统支持两种方式：

### 方式一：页面临时输入

在目标检测页面点击“设置 API Key”，输入 Key 后即可使用。该方式只保存在当前浏览器会话中，关闭浏览器后失效。

### 方式二：本地文件配置

在项目根目录创建 `.deepseek_api_key` 文件，并将 API Key 放入文件中。该文件已被 `.gitignore` 忽略，不会作为项目代码提交。

```text
.deepseek_api_key
```

如果不配置 API Key，系统仍可以使用基础检测功能，小 Y 助手也会提供本地兜底回答。

## 注意事项

- 检测某个场景前，建议先确认模型管理中是否存在对应场景模型。
- 如果场景没有匹配模型，系统会提示未找到对应模型，此时需要上传符合命名规则的模型。
- 通用检测可以使用默认 `models/yolov8n.pt`。
- 同一场景可以上传多个模型，检测页会提供模型下拉框供选择。
- 检测图片或视频较大时，处理时间会增加。
- AI 分析结果是辅助说明，不能完全替代人工判断。
- 火灾、病虫害等场景涉及风险判断时，应结合现场情况进行复核。

## 项目特点

- 多场景检测：将单一目标检测扩展为通用、无人机、火灾、花卉、病虫害等多个场景。
- 自动模型切换：用户选择场景后，系统自动加载匹配模型。
- 多模型选择：同一场景支持多个模型版本，便于对比不同训练效果。
- 可视化结果：检测框、类别、置信度和统计数据清晰展示。
- 历史可追溯：图片和视频检测任务自动保存，方便复查和下载。
- AI 解释增强：不同场景使用不同 AI 角色生成分析内容。
- 小 Y 项目助手：帮助用户了解系统功能、页面分布和使用方式。


## 无人机检测实验与权重

无人机实验的交付权重为 `models/drone_yolov8n_v1.pt`（单类别 drone），由 SSSteven0629 单独上传。上传后在平台选择“无人机检测”即可加载；文件摘要和上传说明见 [模型说明](models/README.md)。

训练包含基础组与增强组各 30 轮，按验证集选模；独立测试集 201 张图片的 mAP50 为 **85.90%**、mAP50-95 为 **56.34%**。复现命令、数据划分、逐轮记录与适用范围见 [实验说明](experiments/drone/README.md) 和 [实测报告](experiments/drone/实验报告.md)。
