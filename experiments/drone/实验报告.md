# 无人机检测实验报告

本次实际完成两组 YOLOv8n 微调实验，每组 30 轮。按验证集 mAP50-95 选出 **augmented**，交付权重为 `models/drone_yolov8n_v1.pt`。此报告由真实运行结果生成。

## 数据与方法

公开数据集 YOLO Drone Detection Dataset v1 原有 1,359 张图，移除 20 张完全重复图后为 1,339 张。按近重复及编号分组重新划分为训练 937、验证 201、测试 201 张，检测类别为 drone。固定划分清单和源文件 SHA256 随包提供。

一张训练图片 pic_722.jpg 缺少 JPEG 结束标记，原运行中由 Ultralytics 自动修复；复现脚本已显式实现同样的修复并验证输出摘要，修复记录见 image_repairs.json。其他图片与原始清单摘要一致。

两组均从同一官方 YOLOv8n 权重开始，输入 416、batch 16、AdamW、初始学习率 0.001、种子 20261013、AMP 关闭。区别仅为 README 所列的颜色/几何/Mosaic 增强。训练环境为 NVIDIA GeForce RTX 4060 Laptop GPU，PyTorch 2.5.1+cu124，Ultralytics 8.3.226。完整参数见各组 args.yaml。

## 独立测试集结果

测试集共 201 张、235 个标注框，输入分辨率 416。

- Precision：0.8896
- Recall：0.8468
- mAP50：0.8590
- mAP50-95：0.5634

以上值范围为 0–1。评估置信度下限 0.001、NMS IoU 0.7；Precision/Recall 是 Ultralytics 评估曲线对应的工作点，不是演示阈值 0.25 下的固定工作点成绩。推理阶段平均耗时为 0.89 ms/张（验证器测得，不能直接当作浏览器摄像头端到端 FPS）。

固定演示阈值 0.25、匹配 IoU 0.5 的逐图复核统计：TP=195、FP=25、FN=40，Precision=0.8864、Recall=0.8298。此处使用按分数排序的一对一贪心匹配；逐图记录及错误最多的样本见 error_review.json。

## 局限与后续工作

验证集和测试集没有纯背景样本；大量图片是产品图、近景或视频帧，远距离小无人机和无目标场景代表性不足。近重复分组降低了泄漏风险，但缺少完整视频来源标识，不能证明消除了所有相关图像。当前结果适合课程实验和功能演示；下一步应增加鸟类、飞机、空天空等负样本，进行真实摄像头视频测试，并用多个随机种子评估稳定性。
